# Source taxonomy

The workbook mixes primary legal instruments with contextual and historical material. The repository separates them as follows:

| Category | Included material in the supplied workbook | Treatment |
|---|---|---|
| Current norm | Decrees 12.642/2025, 9.013/2017, and 3.029/1999; RDC 839/2023, 727/2022, and 429/2020; Portarias 558/2022 and 240/2021; IN MAPA 22/2005; IN 75/2020 | Primary legal basis; verify current status before publication |
| Historical norm | RDC 259/2002, RDC 360/2003, and RDC 359/2003 | Context only; not presented as current law |
| Preparatory act | No item identified in the official-document list | Category retained for future updates |
| Legislative proposal | No item identified in the official-document list | Category retained for future updates |
| Tertiary source | GFI Brazil declaration cited in the extraction matrix | Contextual commentary; not treated as a legal instrument |

`data/processed/official_documents.csv` contains the 13 rows from the official-document worksheet and adds `source_category`. The original titles, excerpts, and institutional names are retained as source evidence; the analytical labels and documentation are in English.
